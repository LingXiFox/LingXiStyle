# Texel 1.9.1 跨平台界面设计

- 日期：2026-11-12
- 适用版本：1.9.1（build 11）
- 平台：iPhone、iPad、Mac
- 基准：1.8.1 的狐橙视觉与 `App/Sources/DesignSystem/Tokens.swift` 设计令牌

## 1. 目标与约束

1.9.1 不重做品牌视觉，只在现有 iPhone 界面上加入成果保险箱、任务历史与多档 Pro，并为
iPad 与 Mac 提供原生布局。所有颜色、间距、圆角、字体继续走 `Tokens.swift`；交互强调色
只用狐橙 `#E8A13A`，每屏最多一个强调填充。

## 2. iPhone（延续 1.8.1）

- 首页：品牌标记、标题、三条权益、主按钮。顶部工具条新增「成果保险箱」入口（`shippingbox`，
  有成果时带 6 pt 狐橙圆点），与额度徽章、设置并列。
- 设置：新增「成果与记录」分组，包含「成果保险箱」（显示保留中数量）与「任务历史」
  （显示记录条数），下方一句说明「转换成果会在设备上保留一段时间，重新保存不占用免费额度」。
- 成果保险箱：保留数量 / 占用空间 / 设备可用空间摘要卡、保留期限菜单（3 / 7 / 14 / 30 天 /
  永久）、清理过期、列表行（56 × 70 缩略图、LIVE 徽章、剩余时间、大小、重新保存、分享、
  删除）。空态使用 `shippingbox` 图标与两句说明。
- 任务历史：任务卡默认折叠，显示时间、成功 / 失败 / 取消计数与状态胶囊；展开后逐项显示
  状态图标、失败原因或输出大小，有保险箱记录的项提供「重新保存」。
- Pro 购买页：四档单选（24 小时通行证 / 周订阅 / 月订阅 / 永久版），价格只读
  `Product.displayPrice`；权益卡三项；已购状态卡（有效期或「永久生效」+ 管理订阅）；
  免费体验卡（可领取 / 剩余时间 / 已领取）；恢复购买与法务说明。

## 3. iPad（原生布局）

- 首页使用两栏：左列品牌、标题与权益，右列 380 pt 宽的选择卡（选择照片 / 从文件导入），
  整体限宽 980 pt 并居中，避免全宽拉伸。顶部工具条与内容同宽。
- 选择 / 处理 / 结果页限宽 `iPadContentMaxWidth`（720 pt）加安全边距，底部操作栏保持全宽。
- 设置、保险箱、任务历史、Pro 在 regular 宽度下以整页 sheet 呈现（`presentationSizing(.page)`），
  导航标题与返回按钮可见；compact 宽度仍为 sheet / push。
- 支持横竖屏、多窗口与拖放：首页选择卡接受 HEIC URL 拖入，拖入时描边狐橙。

## 4. Mac（独立原生界面）

- `NavigationSplitView`：侧栏「转换 / 成果保险箱 / 任务历史」，宽 196–260 pt；底部显示品牌、
  今日额度与「升级 纹粒 Pro」。
- 转换页：拖放区（整窗高亮）、导出文件夹行、队列行内状态（检查中 / 待转换 / 转换中 /
  已保存 / 失败 / 取消 / 待额度）、汇总卡与底部操作栏。快捷键 ⌘O 导入、⌘R 开始、⌘. 取消。
- 保险箱：左侧列表 + 右侧详情（大预览、元信息网格、导出 / 在 Finder 中显示 / 删除）。
- 任务历史：任务卡 + 展开明细，与 iPhone 共用文案 key。
- 设置窗口 560 pt 宽：转换、成果与记录、Pro、关于四组；Pro 方案以 560 × 640 sheet 呈现。
- 字体与颜色使用 `MacTokens.swift`，与 iOS 令牌同名同值，暗色模式随系统。

## 5. 状态覆盖

| 状态 | iPhone / iPad | Mac |
| --- | --- | --- |
| 空 | 保险箱、历史空态插画与说明 | 侧栏页面空态 |
| 执行 | 逐项阶段、真实进度、可取消 | 行内阶段 + 操作栏进度 |
| 成功 | 结果页统计、分享、查看保险箱 | 汇总卡 + 在 Finder 中显示 |
| 失败 | 失败原因与诊断码、重试 | 同行提示 + 重试未完成 |
| 取消 | 取消项标记、可重试 | 同行标记 |
| 恢复 | 启动提示「上次有 N 个任务中断」 | 同样的提示条 |
| 过期 | 保险箱行显示已过期、清理入口 | 同左 |

## 6. 无障碍与本地化

- 触控目标不小于 44 pt；Dynamic Type 使用 `@ScaledMetric` 与语义字体。
- 循环动画尊重 Reduce Motion。
- 四语言 zh-Hans / zh-Hant / en / ja 全部走 String Catalog，无拼接文案；价格不写死货币。

## 7. 验收基准
