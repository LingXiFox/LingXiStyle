## 2. 页面清单

### iPhone（6 张）

1. 首页：品牌、今日免费额度、选片入口。
2. 已选照片：3 张左右 HEIC 缩略图、继续添加、开始转换。
3. 转换中：真实阶段（读取 / 下载 / 处理 / 保存）与真实进度。
4. 结果页：新 Asset、HEIC 回读确认、应用内预览 / 分享。
5. 成果保险箱：保留剩余时间、占用空间、重新保存 / 导出。
6. Pro：四档方案与实时 `Product.displayPrice`；或今日额度用完页。

### iPadOS（6 张）

1. 首页两栏：左侧品牌文案，右侧选片卡；展示 iPad 原生布局。
2. 首页横屏：同一两栏在横屏下的留白与可点击区域。
3. 选片 / 拖放：从「文件」拖入 HEIC 或整个文件夹。
4. 转换中 / 结果：队列与真实阶段，不伪造进度。
5. 成果保险箱：列表 + 预览，展示保留期与重存按钮。
6. 任务历史 / Pro：展开的任务卡，或四档 Pro 与订阅管理入口。

### macOS（6 张）

1. 转换：侧栏 + 拖放区 + 导出到文件夹。
2. Finder 导入：真实 NSOpenPanel 或拖放后的队列。
3. 转换中：真实阶段、取消按钮与快捷键提示。
4. 成果保险箱：列表、预览、导出与「在 Finder 中显示」。
5. 任务历史：任务卡展开、失败原因、从保险箱重存。
6. Pro / 设置：四档方案、试用卡、订阅管理、沙盒导出目录设置。

## 4. 捕获与验收

1. 用真实 App 与有再分发授权的 HEIC 样片，不用 `Tests/Fixtures/IMG_5296.HEIC`。
2. iPhone 用 6.9 英寸模拟器；iPad 用 12.9 / 13 英寸模拟器，分别拍竖屏与横屏；Mac 用真实窗口，不用 iPad 界面冒充。
3. 四种语言分别启动：`-AppleLanguages` 只影响该次启动，不写入用户偏好。
4. 逐张核对：无隐私信息、无虚构价格、无未验证功能、无“已通过审核”之类的未发生状态。
5. 捕获后放入本地 `AppStoreScreenshots/1.9.1/<platform>/<language>/`，不提交公开仓库；上传 App Store Connect 前由主人确认样片授权与平台顺序。
