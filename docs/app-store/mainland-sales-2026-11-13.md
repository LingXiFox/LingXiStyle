# Texel 中国大陆商品销售配置

2026-11-13，主人明确要求中国大陆适配销售。本轮将四档商品的销售范围由排除 CHN 的 174 个地区补为包含 CHN 的 175 个现有地区，没有提交审核或发布 1.9.1。

## 已执行与回读

App 本身的 CHN 状态在修改前已为 `available: true`、`contentStatuses: [AVAILABLE]`，本轮没有重新修改 App 地区配置。

| 商品 | 大陆价格（CNY） | 配置 |
| --- | ---: | --- |
| 日卡 | ¥3 | 非续期订阅，24 小时；开放 CHN |
| 周订阅 | ¥8 | ONE_WEEK / UPFRONT；开放 CHN 并新增大陆价格点 |
| 月订阅 | ¥15 | ONE_MONTH / UPFRONT；开放 CHN 并新增大陆价格点 |
| 永久 | ¥58 | 原有非消耗型；开放 CHN |

- 价格取自 Apple 对已批准美国基准价的现有自动定价或 equalization，不使用自行计算的汇率。
- 日卡、永久通过官方 `POST inAppPurchaseAvailabilities` 更新完整地区列表，保留原有地区并增加 CHN。
- 周、月通过官方 `PATCH subscriptionPlanAvailabilities/{id}` 更新现有 UPFRONT 计划的地区关系，再添加 CHN 价格。
- 四档商品地区数均回读为 175；周、月新增大陆价格后，原 174 个地区价格点与修改前完全一致。
- 日卡与永久的美国基准价仍为 $0.49 / $7.99；原自动生成的大陆价格点保持不变。未来地区开关仍关闭。
- iOS 1.9.1（11）保持 `PREPARE_FOR_SUBMISSION`；新商品仍需随 App 版本提交审核，配置地区不等于商品已经获批或完成真实购买验证。

修改前完整快照、价格计划、逐项写入与回读证据保存在本地 `build/asc-mainland-20261113/`。仅操作本机已配置的官方 ASC 客户端，未改 App 的 StoreKit 价格显示逻辑、未新增依赖。

## 发布脚本同步

`tools/release_appstore.py` 的地区计划、执行校验与回读结果已改为包含全部现有地区，不再自动排除 CHN。旧的排除大陆计划会被拒绝，避免后续运行时关闭大陆销售。

35 项离线测试通过，包含新增大陆的写入与价格保持测试，以及原来的禁止审核提交、计划篡改与凭据保护测试。未修改 App 业务代码，不需要为地区配置重新上传构建。

## 距离正式提交的剩余项

- 尚未把 1.9.1、日卡、周/月订阅及订阅组加入同一审核草稿，也未执行添加审核阶段的完整校验。
- 周/月商品旧 API 状态与网页状态此前不一致；不得以已有价格与截图代替最终提审校验。
- 真机 TestFlight / Sandbox 的商品加载、购买、恢复、续期与撤销仍未验证。
- 普通 iPhone 六张截图仍为旧版；本轮只补拍了 iPad 和 Duo 外屏。
- 线上隐私与支持页可在 Chrome 正常打开，但内容仍旧：隐私页写旧 Bundle ID `com.lingxifox.LingXiStyle`，支持 FAQ 仍写 Pro 为一次性永久购买、不是订阅；页脚仍称未上架。本轮没有修改或部署该独立网站。
- 当前版本发布方式为 `AFTER_APPROVAL`，即审核通过后自动发布；如果需要人工放行，提交前需改为手动发布。
- macOS 商店平台、Mac 签名构建与 Mac 截图尚未准备；本轮提交目标仍为 iOS / iPadOS。
